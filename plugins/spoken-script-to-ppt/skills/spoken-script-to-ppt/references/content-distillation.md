# 口播内容筛选规则

## 1. PPT 的角色

PPT 是口播中的视觉锚点，不是口播文案的摘要。

- 口播承担：解释、铺垫、故事、情绪、例子和细节。
- PPT 承担：结论、结构、证据、关系、步骤、警告和行动。
- PPT 单独快速浏览时应看懂逻辑主线，但不能完整替代口播。
- 精简不能改变原意、语气强度或因果关系。

## 2. 按语义拆成信息单元

以下信号通常开始一个新单元：

- 新问题、新结论或新对象；
- “但是、然而、真正的问题是”等重大转折；
- “所以、这意味着、因此”等推论；
- 数据、研究、案例或具体证据；
- “第一、第二、第三”等步骤；
- 从现象转原因、从原因转方案；
- 场景、时间、人物发生变化；
- 总结、建议或 CTA。

以下组合通常不要拆开：

- 结论与紧随其后的必要解释；
- 数据与它直接证明的结论；
- 问题与紧接着给出的答案；
- 案例背景与案例结果；
- 脱离相邻环节就无法理解的因果链。

每个信息单元记录：

```text
paragraph_ids:
source_span:
content_type:
one_sentence_meaning:
logic_required:
precision_required:
visual_relationship:
display_score:
treatment:
visible_copy:
oral_only:
cue_phrase:
```

## 3. 内容类型与处理方式

| 内容类型 | 默认处理 |
|---|---|
| 总论点、分论点、结论 | 提炼成结论式标题 |
| 原因、机制、因果链 | 转成流程、箭头或结构关系，解释留给口播 |
| 数据、比例、趋势 | 转成图表，只突出最有证明力的 1–3 个数字 |
| 对比、转折、前后变化 | 左右分屏、Before/After 或旧认知/新认知 |
| 操作步骤 | 保留“动词 + 对象”的步骤名 |
| 定义、关键概念 | 概念名 + 一句极短定义 |
| 案例 | 显示场景、关键动作和结果；过程由口播讲 |
| 类比、比喻 | 转成形象插画，不把整段解释写出来 |
| 核心反对意见 | 可变成问题页；次要质疑只口述 |
| CTA、关键警告 | 必须屏显，表达具体 |
| 权威引用 | 只有“谁说的”本身构成论据时才显示 |
| 情绪、幽默、悬念 | 由画面、节奏或留白承载 |
| 过渡、铺垫、背景解释 | 默认只口述；必要时提炼一个场景 |
| 重复说明、寒暄、口头语、自我提示 | 删除或只保留表达最强的一次 |
| 次要例子 | 选一个最有代表性的视觉化，其余口述 |
| 限定条件 | 影响准确性、安全或合规时必须保留在画面或脚注 |

## 4. 五种处理状态

- `OWN_SLIDE`：该单元本身造成独立认知转变，合并后会出现两个焦点，或需要单独停留查看的重要证据、结论、步骤、警告或 CTA。
- `MERGE`：单元没有独立认知任务，但直接解释、证明、限定或回答相邻的 `OWN_SLIDE`。结论后的证据/限定默认向前合并；为下一结论铺垫的问题/场景默认向后合并；不得跨越重大转折合并。
- `VISUAL_ONLY`：单元不需要精确屏显文字，也不构成独立结论，但其动作、情绪、场景或比喻能成为相邻页面的主/辅助视觉。
- `ORAL_ONLY`：单元对讲述仍有意义，但视觉化收益低，或其价值主要来自解释、语气、故事和铺垫；只进入口播映射或 speaker notes。
- `EXCLUDE`：寒暄、口头填充、制作提示、完全重复或没有独立信息的修饰，不参与页面和备注设计。

单一判定优先级：强制覆盖项 → 是否构成独立认知任务 → 是否直接支持相邻核心页 → 是否只有视觉价值 → 是否仍有口述价值 → 删除。评分只帮助比较，不得推翻这个优先级。

## 5. 显示还是口述：决策树

依次判断：

1. 删除后，听众是否会失去结论、逻辑、证据、步骤、警告或行动要求？
   - 否：若仍承担故事、语气或必要铺垫，标为 `ORAL_ONLY`；若只是填充或重复，标为 `EXCLUDE`。
   - 是：继续。
2. 听众是否必须看到精确内容？关键数字和单位、新术语、步骤名、对比对象、结论、CTA、关键限制通常需要看到。
   - 是：保留最短的精确文字，然后继续第 3 步；“需要精确显示”本身不决定页面状态，仍要按独立任务、相邻支持或视觉价值选择五种状态之一。
   - 否：继续。
3. 画面、图表、流程或图标是否比文字更快解释？
   - 是：若单元构成独立认知任务，标为 `OWN_SLIDE`；若直接支持相邻核心页，标为 `MERGE`；若只有场景或隐喻价值而无独立信息，标为 `VISUAL_ONLY`。
   - 否：继续。
4. 这是故事、解释、铺垫、情绪或修辞吗？
   - 是：默认 `ORAL_ONLY`；若它没有需口述的新信息、只有场景或隐喻价值，改为 `VISUAL_ONLY`。
   - 否：若直接支持相邻页则 `MERGE`，否则按是否形成独立任务决定 `OWN_SLIDE` 或 `EXCLUDE`。
5. 是否与前文重复？
   - 完全重复：`EXCLUDE`。
   - 部分重复：只把新增信息按上述规则分类。
   - 用于总结：若形成独立收束任务则 `OWN_SLIDE`，否则 `MERGE`；必须重新组织，不原样复制。

## 6. 展示评分

评分对象是信息单元，不是单句：

```text
展示分 =
2 × 重要性
+ 逻辑必要性
+ 视觉化收益
+ 证据强度
+ 记忆/行动价值
- 口述优势
- 重复度
```

| 维度 | 范围 | 判断 |
|---|---:|---|
| 重要性 | 0–3 | 0 口头填充；1 辅助；2 关键支撑；3 核心论点或 CTA |
| 逻辑必要性 | 0–2 | 删除后逻辑是否断裂 |
| 视觉化收益 | 0–3 | 0 无收益；1 泛化图标；2 插画/关系图；3 强图表/流程/场景 |
| 证据强度 | 0–2 | 无证据、具体案例、可核实数据/事实 |
| 记忆/行动价值 | 0–2 | 听众之后是否需要记住或执行 |
| 口述优势 | 0–2 | 故事、情绪和铺垫越适合口述，扣分越高 |
| 重复度 | 0–2 | 已表达越充分，扣分越高 |

处理阈值：

- `10+`：`OWN_SLIDE` 候选；若它只是直接证据或限定，仍按优先级归入 `MERGE`。
- `7–9`：默认 `MERGE`；没有精确屏显价值、但视觉化收益至少为 2 时用 `VISUAL_ONLY`。
- `4–6`：默认 `ORAL_ONLY`；只有场景/隐喻价值时用 `VISUAL_ONLY`。
- `3` 及以下（包括负分）：有必要口述价值时用 `ORAL_ONLY`，否则 `EXCLUDE`。

强制覆盖高于评分：核心结论、关键步骤、CTA、影响理解的数字、关键警告和安全/合规信息不得遗漏。

## 7. 合并与拆分

先问相邻内容是否共同完成一个不可分割的认知任务：

- 数据只有与紧邻结论一起才有意义，或问题在下一句直接回答且不需要悬念时，合并。
- 证据需要独立停留查看、使用不同主视觉、包含多组数据，或答案本身是重大反转时，拆页。
- 若“合并规则”和“拆分规则”同时命中，以是否能在一页保持单焦点、以及是否需要独立停留为最终裁决。

适合合并：

- 同一个结论及其一个直接证据；
- 同一因果链中紧密相连的 2–4 个节点；
- 同一案例的“问题 + 结果”；
- 同一对比关系的两个对象。

通常拆页；但若与上面的单焦点/独立停留裁决冲突，以该裁决为准：

- 同时出现两个能独立成立的结论；
- 需要两种不同的数据或关系图逻辑；
- 从问题切换到解决方案；
- 从观点切换到关键证据；
- 出现重大转折或认知反转；
- 流程超过 5 个节点；
- 案例同时包含复杂背景、过程和结果。

连续几段若只解释同一观点，不逐段切页，让一张核心画面覆盖整段口播。

## 8. 屏显文字预算

`visible_text_count` 分别记录标题、叙事正文和节点/标签字数。观众可见的标题、正文、标签和大数字都要计数；图表坐标、直接数据标签、单位和必要来源脚注不计入叙事正文预算，但仍应最少化并保持可读。

普通观点、证据、案例和对比页：

- 标题理想 8–16 个汉字，硬上限 22 个；标题应表达判断，而不是只写主题名。
- 正文理想 0–30 个汉字，硬上限 40 个。
- 最多 3 个正文文字组或 3 个列表项。
- 图示标签建议不超过 6 个汉字。
- 一页重点数字不超过 3 个，核心数字最好只有 1 个。
- 引用建议不超过 20 个汉字并标明人物或来源。
- 不出现完整段落；先删减或换版式，不能靠缩小字号解决。

步骤、分层、分类和流程页：

- 允许 3–5 个必要节点，每个节点建议不超过 6–8 个汉字。
- 标题单独计数；节点之外最多增加 1 个不超过 12 个汉字的诊断或结论标注。
- 不再叠加正文段落。超过 5 个节点时先合成 3 个阶段，再分页面展开。

封面只有主标题和必要署名/副标题；钩子页可以用一句短问题；引用页只有一条短引用及来源。蓝图中 `message_headline` 应在 `visible_copy` 中出现一次，不能再用近义副标题重复同一信息。

## 9. 页数与节奏

页数由认知任务决定，时长公式只用于检查：

- 用户在文字原稿之外另附了已对齐音频时，以真实时长为准；本 skill 不负责把原始音视频转写成文案。
- 只有中文原稿时，可按每分钟约 220–260 个汉字估算。
- 现场演讲或课程：通常每个内容页承载约 35–60 秒口播。
- 录播、信息流或节奏较快的视频：通常每个内容页承载约 12–30 秒口播。
- 重大数据、认知反转或 CTA 可以单独成页。
- 封面、必要的章节页和结尾页另计；不要为了凑页数增加空洞章节页。

## 10. 超载时的删减顺序

依次转入口述或删除：寒暄与口头语 → 重复表达 → 普通过渡 → 解释性长句 → 次要案例 → 次要证据和数字 → 不影响准确性的限定。

不得删除：核心论点、观点成立所依赖的关键证据、不可缺失的因果环节、必须执行的步骤、CTA、影响准确性或安全性的限制。

## 11. 内容审计

- 核心观点是否全部覆盖？
- 同一内容是否重复展示？
- 屏显数字、术语和结论是否忠于原文并可追溯？
- 每页是否保留了口述空间，而不是把口播重新抄了一遍？
- 页面是否在口播讲到之前提前泄露了后续结论？
